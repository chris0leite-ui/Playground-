# §5 Engine refactor sequence (T0.0 … T0.11)

Each step is one commit. After each, the game still runs and looks the same. No new content lands in T0.

- **T0.0 Split this plan.** Create `docs/plan/01-repo-layout.md` … `11-verification.md` mirroring §1–§11. Only doc changes.
- **T0.1 Move `js/` → `js/engine/`.** Rename `game.js` → `engine/loop.js`. Update `<script>` tags. Pure file moves, zero logic change.
- **T0.2 Region abstraction.** New `engine/region.js`. Add `state.world = { regions:{}, currentRegionId }` and `state.region`. Adapt `tileAt`/`isSolidAt` (util.js:18-29), `tryMove` clamp (player.js:49), `drawMap` (map.js:93), `drawEntities` (render.js:3), `updateCamera` (game.js:20) to read `state.region`. `loadRegion(id)`, `unloadRegion(prev)` stash entities in a memo.
- **T0.3 Entity registry.** New `engine/entity_registry.js`: `registerEntityType(id, {update, draw, factory})`, `updateEntity`, `drawEntity`. Move each existing type into `engine/entity_types/<t>.js` (player, npc_actor covering orc+guard, horse, pickup, projectile-stub). Delete the switch in `render.js:20` and `ai.js:3`.
- **T0.4 Generalized actor.** New `engine/actor.js`: `makeActor(defaults)` merges class stats, inventory, faction, disposition. `makePlayer`/`makeOrc`/`makeGuard` become thin wrappers. Remove `p.wantedLevel`/`p.wantedDecay` (superseded by faction rep in T0.6). Replace `onEnemyKilled` (player.js:102) with data-driven `on_killed` + `eventBus.emit('entity_killed', …)`.
- **T0.5 Dialogue engine.** New `engine/dialogue.js`: `openDialogue(id, ctx)`, `advance(choiceIdx)`, `closeDialogue()`. Reuses `#message-overlay` (hud.js:47) with choice `<button>`s. Add `state.inputMode = "world"|"dialogue"|"menu"|"overworld"`; `input.js` dispatches by mode. Condition/effect evaluators live here, reused by T0.6.
- **T0.6 Quest + faction.** `engine/quest.js`: `state.quests`, `startQuest`, `advanceQuest`, step-type registry. Subscribes to event bus. Minimal quest-log UI in `hud.js`. `engine/faction.js`: `state.reputation`, `getRep`, `modRep`. NPC hostility derives from faction + disposition. Old "wanted stars" is a view over `rep[citadel-guard]`.
- **T0.7 Overworld.** `engine/overworld.js`: `M` key toggles `inputMode="overworld"`, draws macro-map from `W.overworld` + each region's `overworld_pos`. Clicking a region → `loadRegion(id)` at its `spawn_point`. Free after first on-foot visit.
- **T0.8 Edge transitions.** In `updatePlayer` post-move, if player crosses region bounds and `region.def.neighbors[dir]` is set, `loadRegion(neighbor)` placing them at mirrored coord on the opposite edge.
- **T0.9 Save/load.** `engine/save.js`: serialize `{version, class, stats, inventory, reputation, quests, flags, currentRegionId, regionMemo}` to `localStorage["me-save-<slot>"]`. Version check against `W.schemaVersion`; mismatched save → graceful error. Autosave on region transition.
- **T0.10 Bow + stealth.** `engine/entity_types/projectile.js` (straight-line move, tile/entity collide). `engine/combat.js`: `tryMelee` (extracted from player.js:70), `tryShoot(actor, angle)`. Stealth: actor `stealth` stat; `npc_actor.update` computes `detectionLevel` from distance + LOS + speed + stealth; aggro only above threshold. Ranger/Hobbit get `signature_ability: stealth` (stat multiplier — no engine switch on class).
- **T0.11 Load order.** Finalize `index.html` per §6. Verify `file://` boot.
