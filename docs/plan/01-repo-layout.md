# §1 Repository layout

```
build.js                          # Node compiler (no npm)
build/                            # per-concern parsers/validators/emitters
  parse_frontmatter.js
  parse_tilemap.js
  parse_dialogue.js
  parse_quest.js
  validators.js
  emit.js
  schemas.js
content/                          # AUTHORING — source of truth
  index.md                        # (auto-regen) human index
  INDEX.json                      # (auto-regen, committed) machine index
  _schemas/                       # one file per content type
    region.md … encounter.md … tilemap.md
    _examples/*.example.md        # one canonical example per type
  regions/<id>/
    region.md  map.md  _index.md (auto)
    settlements/ buildings/ npcs/ quests/ encounters/ dialogues/
  factions/<id>.md
  classes/<id>.md
  items/<id>.md
  arcs/<id>.md
  overworld.md
js/
  engine/                         # refactored engine, each file ≤150 lines
    config.js util.js state.js input.js loop.js render.js hud.js
    region.js actor.js entity_registry.js combat.js
    dialogue.js quest.js faction.js save.js overworld.js
    entity_types/{player,npc_actor,pickup,projectile,horse}.js
  world/                          # GENERATED, committed, never hand-edited
    _manifest.js regions.js tilemaps.js settlements.js buildings.js
    npcs.js dialogues.js quests.js items.js factions.js classes.js
    arcs.js encounters.js overworld.js
docs/plan/                        # this plan, split per §
index.html
```

## Rules
- `content/` is the authoring surface (source of truth).
- `js/world/` is generated (banner-commented `// GENERATED — do not edit by hand`).
- Both are committed — preserves `file://` play and makes PR diffs reviewable.
- A region is the unit of authoring **and** of agent context — all region-X files live under `content/regions/X/`.
- Cross-region entities (factions, classes, items, arcs, overworld) live at top level because multiple regions reference them.
- `_schemas/` lives inside `content/` (not a top-level `docs/`) so a region-author agent grabs schemas + examples + region folder in one directory walk.
- `_index.md` + `INDEX.json` are regenerated by `build.js` and banner-commented AUTO-GENERATED.
